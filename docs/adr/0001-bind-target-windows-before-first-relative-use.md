# Bind target windows before first relative use

A window-relative recording may address multiple target windows, so Remember binds every target automatically before its first targeted operation and waits up to 30 seconds for a candidate to appear. The recorded initial/deferred availability is metadata rather than a preflight requirement, because Windows host processes can reuse an already-existing top-level window for content opened during recording. Remember considers only unoccupied windows with an exact executable-path and window-class match and compatible initial client-area size and DPI, ranks them by recorded-title similarity and stable window order, and selects the highest-ranked candidate without prompting. A binding lasts for one continuous window lifetime, playback preflight never rejects, launches, or wakes a target, and loop playback reuses a binding only while the same window instance survives.
