# Bind independent windows, not transient surfaces

Independently movable top-level windows and dialogs receive distinct target identities, while child controls and short-lived menus, dropdowns, and context menus use the owning target window's coordinate reference; non-interactive tooltips are ignored for targeting. Pointer movement that merely crosses a background window remains screen-relative, but a wheel action over a real background window is target-relative without activating it. Windows Shell surfaces, including the desktop, taskbar, Start menu, notification area, and task switcher, always remain screen-relative and are never bound. This keeps independently positioned dialogs and intentional background scrolling accurate without making recordings depend on unstable transient or system identities.
