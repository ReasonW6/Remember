# Restore target windows only when needed

Remember does not open, restore, or activate every recorded target during playback preflight. When targeted pointer input or a targeted keyboard sequence is about to operate an existing minimized or hidden target, Remember restores and activates that window just in time, then applies the normal identity and geometry checks. A keyboard sequence is checked only at its start so focus-changing shortcuts can complete naturally. An activation click is injected without waiting for the clicked window itself to become foreground, because launcher surfaces may close and open a different foreground window only after button release; the next targeted operation validates and, when required, establishes its own foreground target. Unexpected divergence at that actual operation still stops playback rather than causing continuous focus stealing.
