# Skip unreadable target intervals

Window-relative recording continues when the pointer or a new keyboard sequence encounters a window whose identity or geometry cannot be read. Remember leaves the user's real input unconstrained, shows a click-through pointer-following warning with the specific cause, and preserves elapsed time so playback holds its last valid pointer position during the gap; Remember control hotkeys remain active. If mouse buttons are already pressed when the pointer enters the unreadable target, the valid gesture prefix is retained and synthetic releases are inserted at the last readable pointer position. When the pointer returns to a readable position while a mouse button remains physically held, Remember inserts a new press and records a separate resumed gesture; playback cannot preserve one continuous drag across an unreadable target. Keyboard readability is evaluated only when a sequence begins: a sequence that began on a readable target, including Alt+Tab, continues through focus changes until all keys are released, while a sequence beginning on an unreadable target is omitted as a whole. This was chosen over stopping the whole recording, rolling back valid input, or silently degrading to screen coordinates, which would make brief unreadable regions disproportionately disruptive, discard valid work, or produce misleading targeting.
